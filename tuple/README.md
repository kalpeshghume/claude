# Python Tuples in 30s (9:16 reel, 1080x1920, 30 fps, 36 s)

- `index.html`: HyperFrames composition (generated by `build.mjs`; edit `build.mjs` and re-run `node build.mjs`, or edit the HTML directly)
- `tuples.srt`, `narration.txt`: captions and voiceover script
- `render.mjs`: stand-in renderer (headless Chrome + ffmpeg) used when the HyperFrames CLI is unavailable

## Render with HyperFrames (on a machine with npm access)

    npx hyperframes check --json
    npx hyperframes preview
    npx hyperframes render --quality delivery -o tuples-reel.mp4

## Add a voiceover

    npx hyperframes tts narration.txt --voice af_heart --output assets/narration.wav

Then add `<audio id="vo" src="assets/narration.wav" data-start="0" data-duration="36" data-volume="1"></audio>` inside `#root`
and nudge caption `data-start` values in `build.mjs` to match the generated audio (`npx hyperframes transcribe` gives word timings).
