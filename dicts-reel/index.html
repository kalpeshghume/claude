RECAP
Remember
Ordered
items keep their position

Save this for later
A tuple is an ordered
collection, created with parentheses.
Access items by index,
starting at zero.
Negative counts from the end.
But tuples are immutable.
Try to change one,
and Python raises an error.
You can unpack a tuple
into variables in one line.
Careful with one item!
You need a trailing comma,
or it's not a tuple.
Use tuples for fixed data,
like coordinates or colors.
