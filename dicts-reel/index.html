Remember

A dictionary stores
key-value pairs in curly braces.
Look up a value by its key,
it's instant.
Use .get() if the key may be missing.
Dictionaries are mutable.
Add or update a key
and the dict changes in place.
Loop over .items()
to get each key and value together.
Missing key?
person["city"] raises KeyError,
so use .get() instead.
Use dicts for labelled data,
like a profile or a config.
